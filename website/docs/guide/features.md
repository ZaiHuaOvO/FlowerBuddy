# 功能概览

## 桌面宠物

桌宠窗口透明、无边框、默认始终置顶。可以拖动位置，单击播放弹簧反馈，右键打开快捷菜单。桌宠图片支持内置预设和用户导入的 PNG/JPEG。

## 快捷菜单

菜单固定为四个图标：功能、设置、隐藏桌宠、退出。

- 悬停“功能”展开模块动作；点击“功能”打开系统页功能 tab。
- 点击“设置”打开系统页设置 tab。
- 菜单优先出现在桌宠上方，空间不足时翻到下方。
- 指针离开菜单和桌宠一段时间后自动关闭。

## 备忘录

- 记录文本、粘贴图片、设置提醒时间。
- 提醒时间支持中文自然语言（如“下周五 3 点”“两个小时后”）和日期选择器。
- 可将备忘录锚定为桌面卡片；卡片标题栏提供加号、锁、完成和关闭。
- 右键卡片标题或正文可在原位编辑正文，约 700ms 自动保存；保存失败会保留内容并提示。
- 逐行打勾可在新建/编辑弹窗或列表中按条开启；开启后卡片每个非空行前显示复选框，完成状态按行号保留，已完成行显示删除线。
- 锁定后卡片其余区域鼠标穿透，只有锁按钮可交互；托盘菜单提供“解锁全部桌面卡片”。
- 关闭表示取消锚定，备忘录正文和数据仍保留。

## 定时提醒

管理多个重复提醒，支持分钟/小时间隔、多段生效时间、± 随机值和常驻气泡。提醒只在设定时段内触发；未设置时段时全天生效。

## 网站检测

添加 HTTP(S) URL 后，可从本机检查状态码、耗时和错误类型，支持手动检测和 5/10/15/30 分钟定时检测。检测结果只代表本机网络，不代表全球可用性。

## DeepSeek 余额

使用自己的 DeepSeek API Key 查询账户余额，支持手动刷新和 15/30/60 分钟自动刷新。官方没有账号级每日消费接口，因此不显示“今日花费”。

## 阿里云 ESA 流量

使用只读 RAM 子账号查询站点过去 24 小时、7 天、30 天的流量，可设置快捷气泡显示哪些范围。ESA 数据可能被采样并存在统计延迟，不能当作精确账单。

## 老板键与模块管理

- 老板键默认 `Alt+Z`，可一键隐藏/恢复桌宠、气泡、系统页、桌面卡片和托盘图标。
- 各功能可独立启用、停用和排序；未启用的功能不出现在功能页导航中。
