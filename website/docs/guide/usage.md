# 使用指南

::: warning 版本说明
当前公开版为 **v0.1.0**。以下系统页“功能 / 设置 / 关于”、卡片操作、原位编辑和逐行打勾等内容属于 v0.2.0 开发中的改动，尚未公开发布；请以 [GitHub Release](https://github.com/ZaiHuaOvO/FlowerBuddy/releases/latest) 说明为准。
:::

## 打开系统页

右键桌宠打开快捷菜单，点击“功能”或“设置”。两者进入同一个系统窗口：

- **功能**：左侧列出已启用模块，主区域显示该功能的真实内容。
- **设置**：左侧为“常规 / 功能管理”，以及有配置项的模块设置；这里不显示业务列表。
- **关于**：显示版本、作者、GitHub 仓库和反馈入口。

## 新建备忘录

- 按 `Alt+A` 打开系统页功能 tab 的备忘录，并弹出新建编辑器。
- 也可以在快捷菜单“功能”动作列表点击“新建备忘录”。
- 在备忘录功能页点击“新增备忘录”。
- 新建弹窗中的“创建后锚定到桌面”开关会被记住。

## 桌面备忘卡片

卡片标题栏操作列从左到右：

1. **加号**：新建备忘录。
2. **锁**：锁定卡片，正文、图片和缩放区域鼠标穿透；再次点击锁按钮解锁。
3. **完成**：完成整张备忘录并关闭卡片。
4. **关闭**：取消锚定并关闭卡片，备忘录数据保留。

锁定的卡片可以从托盘菜单“解锁全部桌面卡片”统一恢复交互。

## 原位编辑正文

右键卡片标题（提醒时间或“备忘”）或正文进入原位编辑：

- 输入后约 700ms 自动保存；
- 输入框下方显示“点击空白处保存”；
- 点击卡片空白处（失焦）、按 Esc/Ctrl+Enter 会立即保存并退出；
- 保存失败时保留编辑内容，并提示“保存失败，点击空白处重试”；
- 编辑期间卡片操作、拖动和缩放暂时不可用；正文增减行后卡片高度会自动适配。

图片的复杂编辑仍请使用功能页的备忘录编辑器。

## 逐行打勾

在新建/编辑弹窗或备忘录列表中按条开启“逐行打勾”后，锚定卡片会为每个非空行显示复选框：

- 勾选/取消只改变该行状态，不自动完成整张卡片；
- 已完成行使用低对比度文字和删除线；
- 完成状态按行号保留，修改该行文本不会移动勾选；新增行默认未完成；
- “设置 → 备忘录设置”中的开关只作为新建备忘录的默认值。

## 提醒时间

在提醒输入框中输入自然语言时间，例如：

- `下周五 3 点`
- `明天上午 9 点`
- `两个小时后`
- `10-20 15:30`

也可以点击“选择时间”使用日期选择器。无法识别的时间会提示错误并阻止保存。

## 老板键

默认 `Alt+Z`。按下后隐藏桌宠、气泡、系统页、桌面卡片和托盘图标；再次按下恢复。可在“设置 → 常规”修改。

## 托盘

双击托盘图标或通过托盘菜单打开系统页。托盘菜单还提供显示/隐藏桌宠、解锁全部桌面卡片和退出。
