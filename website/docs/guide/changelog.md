# 更新日志

## v0.1.0（2026-10-19）

首个公开版本，包含：

- 透明桌宠窗口、快捷菜单、气泡与托盘。
- 备忘录、提醒、桌面锚定卡片。
- 定时提醒、网站检测、DeepSeek 余额与阿里云 ESA 流量。
- 桌宠画廊、老板键与模块管理。
- Windows 安装版、便携版与 ZIP 发布产物。

下载与校验文件见 [GitHub Releases](https://github.com/ZaiHuaOvO/FlowerBuddy/releases)。

## v0.2.0（开发中，尚未发布）

以下改动正在开发，尚未发布；请以实际 Release 说明为准：

- 系统页“功能 / 设置 / 关于”拆分与关于页。
- 系统页布局 v2：统一页面/分组标题、表单行、按钮与输入框高度、焦点样式、窄窗口和弹窗键盘行为。
- 官方 app-icon 接入应用、托盘与安装器。
- 桌面卡片加号、锁、完成、关闭操作与锁定持久化。
- 右键卡片标题或正文原位编辑正文，支持自动保存与高度适配。
- 可选的逐行打勾（每条备忘录独立开关），完成状态按行号保留。
- 快捷菜单“新建备忘录”动作。
- 安装版 GitHub Releases 源应用内更新（关于页检查/下载/确认重启；便携版手动下载）。
- 配置文件某个分区损坏时保留其他有效设置，并备份原文件、显示恢复提示。
- 打包后不再信任开发服务器地址；更新源覆盖仅接受 HTTPS 或本地回环测试地址。
