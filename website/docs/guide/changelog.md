# 更新日志

## v0.1.0（2026-10-19）

首个公开版本，包含：

- 透明桌宠窗口、快捷菜单、气泡与托盘。
- 备忘录、提醒、桌面锚定卡片。
- 定时提醒、网站检测、DeepSeek 余额与阿里云 ESA 流量。
- 桌宠画廊、老板键与模块管理。
- Windows 安装版、便携版与 ZIP 发布产物。

下载与校验文件见 [GitHub Releases](https://github.com/ZaiHuaOvO/FlowerBuddy/releases)。

## v0.2.0（2026-10-21）

本次更新包含：

- 系统页拆分为“功能 / 设置 / 关于”，并重排页面、分组、表单和弹窗布局。
- 接入官方 app-icon，覆盖应用、托盘、安装器和关于页。
- 桌面卡片新增加号、锁、完成、关闭操作；支持右键原位编辑正文。
- 新增逐行打勾，完成状态按行号保留。
- 新增快捷菜单“新建备忘录”动作。
- 安装版支持 GitHub Releases 源的应用内更新；便携版手动下载。
- 新增 VitePress 官网与 GitHub Pages 部署。
- 修复配置文件分区损坏、编辑与勾选冲突、复选框对齐、锁定透明度、设置页行高、弹窗蒙版滚动等问题。
- 打包后不再信任开发服务器地址，更新源覆盖仅接受 HTTPS 或本地回环测试地址。

完整说明与提交 ID 见 [v0.2.0 Release Notes](https://github.com/ZaiHuaOvO/FlowerBuddy/releases/tag/v0.2.0)。
