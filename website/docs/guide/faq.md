# 常见问题

## 为什么 Windows 提示“未知发布者”？

安装包当前未做代码签名，SmartScreen 因此可能显示“未知发布者”。请从官方 [GitHub Releases](https://github.com/ZaiHuaOvO/FlowerBuddy/releases/latest) 下载；如果来源不可信，请不要运行。免费开源签名方案仍在评估，未获批准前不会把未签名包描述为已签名。

## 需要安装 Node.js 吗？

不需要。最终用户只需运行安装版或便携版，不需要打开终端或执行命令。

## 支持 macOS 或 Linux 吗？

当前只支持 Windows x64。没有 macOS/Linux 版本的计划。

## 有应用内自动更新吗？

当前公开版 v0.1.0 没有应用内自动更新，请手动下载新版本安装包覆盖安装；升级会保留个人数据。v0.2.0 起安装版计划支持 GitHub Releases 源检查/下载/确认重启安装，便携版仍手动下载；该功能需真实 Windows 双版本升级验证，以实际 Release 说明为准。

## 数据保存在哪里？

默认在 `%APPDATA%\FlowerBuddy`，包括配置、加密凭据、备忘录、提醒、网站检测、桌宠图片和脱敏日志。卸载程序不会自动删除该目录。

## 卸载会删除我的备忘录吗？

不会。卸载只移除程序文件；如需彻底清除，请在退出花伴后手动删除 `%APPDATA%\FlowerBuddy`。

## DeepSeek 为什么不显示“今日花费”？

DeepSeek 官方没有提供账号级每日消费统计接口。花伴只显示余额，不使用余额差额估算消费。

## 为什么 ESA 只能查国内接入点？

当前固定使用 `esa.cn-hangzhou.aliyuncs.com`。国际站账号可能需要额外接入点选择，属于已知限制。

## 多显示器和缩放支持吗？

应用会在显示器变化时把桌宠和卡片移回可见区域，并针对常见缩放比例做了布局约束。仍建议在真实多显示器和高 DPI 环境中按手动测试计划验收。

## 桌宠跑到屏幕外了怎么办？

当前没有“重置位置”界面入口；可以尝试通过托盘显示桌宠，或在关闭应用后编辑 `%APPDATA%\FlowerBuddy\config.json` 中的 `pet.position`。修改前建议备份该文件。
