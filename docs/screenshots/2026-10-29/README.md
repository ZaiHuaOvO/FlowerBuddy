# 系统页视觉基线 2026-10-29

## 这些截图是什么

- 渲染方式：**Electron 44.8.0 离屏渲染（`offscreen: true`）生产构建产物** `out/renderer/`，通过 `?view=settings` 加载。
- 数据来源：**模拟 `window.settingsApi`**（预置一份启用全部模块、ESA 未配置的假配置）。不是真实用户数据。
- 方式与环境：Windows 11（本机），设备像素比 1.0，未启用系统缩放。
- 采集提交：`b2f907f` 之上的未提交改动（2026-10-29 系统页视觉基座批次）。

## 这些截图不是什么

- **不是 Windows 实机验收**。它们没有验证原生窗口边框、DWM 圆角、系统缩放（125%/150%/200%）、多显示器、中文输入法、托盘与透明窗口。
- **不是真实数据状态**。没有真实 API 凭据、真实余额、真实网络错误。
- 不能用来宣称 VIS-S1–S27 通过；对应条目仍应保持未勾选。
