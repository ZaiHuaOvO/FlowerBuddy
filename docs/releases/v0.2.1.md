# 花伴 v0.2.1

> 发布日期：2026-10-29
> 对比基线：v0.2.0
> 完整提交范围：`v0.2.0..v0.2.1`

## 新增功能

- 本版本没有新增业务功能，主要工作是重做系统页的视觉层级与设置导航结构，并修复一批保存反馈与错误提示问题（`1d9f253`）。

## 问题修复

- 修复保存桌宠缩放比例、备忘录默认值、模块排序、网站与提醒的启用状态时没有任何成功反馈的问题，现在统一显示“已保存”（`1d9f253`）。
- 修复 DeepSeek / ESA 凭据保存失败时只弹全局提示、出错字段本身没有任何标记的问题，错误改为显示在对应字段下方并给输入框加红色描边（`1d9f253`）。
- 修复错误提示插在内容卡上方、导致整个卡片向下位移的问题，改为可关闭的浮层提示（`1d9f253`）。
- 修复左侧纵向导航无法用 ↑/↓ 切换、且缺少纵向语义的问题，顶部 tab 仍使用 ←/→（`1d9f253`）。
- 修复桌宠自定义形象可被单击直接删除、没有确认步骤的问题，现在需要二次点击确认（`1d9f253`）。
- 修复窄窗口布局断点（720px）过于接近最小窗口宽度（640px）、稍一缩小就跳成手机式布局的问题，断点改为 680px（`1d9f253`）。
- 修复空状态文案写作“设置 → 功能”、与实际入口“功能管理”不一致的问题（`1d9f253`）。

## 体验与界面优化

- 系统页移除内容卡投影、导航条自成一层底色以及选中项的边框与投影，改为平面层级，导航不再显得比内容低一层（`1d9f253`）。
- 内容卡边框改为与页面同色温的暖色，圆角收敛为 6/8/12/16 四档，输入框与按钮圆角统一（`1d9f253`）。
- 应用内标题降级为小型品牌行，页面标题升至 20px，分组标题与分组间距加大，层级更清楚（`1d9f253`）。
- 顶部“功能 / 设置 / 关于”改为不带容器的独立胶囊，选中态以暖色填充表达，不再使用阴影和外框（`1d9f253`）。
- 设置页左侧导航收敛为“常规 / 功能管理”两项；模块设置改为功能管理的子页面，页内提供“← 功能管理”返回，功能管理每行为有配置项的模块提供齿轮入口（`1d9f253`）。
- 系统窗口默认宽度由 780 调整为 880，常规页表单不再拥挤；宽窗口下内容列最大 720px 并居中（`1d9f253`）。
- 设置窗口内置 Inter 字体（仅拉丁字母与数字，约 95 KB），版本号、快捷键、余额与统计数字显示更统一；中文仍由微软雅黑渲染（`1d9f253`）。
- 关于页移除渐变背景，与其余页面保持一致（`1d9f253`）。

## 安全与稳定性

- 无安全边界或数据格式变更；配置文件结构、密钥存储、IPC 契约与快捷键含义均未改变（`1d9f253`）。

## 文档与发布

- 设计规范新增“层级模型”“保存模型”“字体”三组规则，并更新截图基线到 `docs/screenshots/2026-10-29/`（`1d9f253`）。
- 手动验收清单新增 VIS-S19–S27（字体实际渲染、错误浮层、字段级错误、保存反馈一致性、模块设置路径等），并把窗口宽度复验改为 640/880/960（`1d9f253`）。
- TODO 记录“模块设置页与功能管理页的启用开关重复”一项，暂缓实施（`1d9f253`）。

## 升级说明

- 覆盖安装即可，配置、密钥、备忘录与导入图片全部保留，本版本没有数据结构迁移。
- 系统窗口默认宽度变为 880×720，最小尺寸仍为 640×540。
- 内置字体使安装包体积增加约 95 KB，其余体积不变。
- 已知限制：系统页的高 DPI 缩放、多显示器与中文输入法仍需 Windows 实机验证；本轮截图来自离屏渲染，不代表实机验收结果。

## 下载建议

- **普通用户推荐下载 `FlowerBuddy-Setup-0.2.1-x64.exe`**：安装版，按当前用户安装，支持覆盖升级和卸载入口。
- `FlowerBuddy-Portable-0.2.1-x64.exe`：便携版单文件，免安装，适合 U 盘或临时使用。
- `FlowerBuddy-0.2.1-x64.zip`：便携版压缩包，包含 Portable EXE、使用说明、MIT 许可证、美术素材许可和第三方许可证清单。
- `latest.yml` 与 `FlowerBuddy-Setup-0.2.1-x64.exe.blockmap`：应用内自动更新元数据，请勿删除；普通用户无需下载。
- `SHA256SUMS.txt`：下载校验值，可用 PowerShell `Get-FileHash` 或 `certutil -hashfile` 核对。
