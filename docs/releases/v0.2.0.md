# 花伴 v0.2.0

> 发布日期：2026-10-21
> 对比基线：v0.1.0
> 完整提交范围：`v0.1.0..v0.2.0`

## 新增功能

- 系统页拆分为“功能 / 设置 / 关于”，业务内容、软件设置与版本信息各自独立（`c3af153`）。
- 系统页布局 v2：统一页面与分组标题、表单行、按钮与输入框高度、焦点样式、窄窗口和弹窗键盘行为（`6b27b30`）。
- 接入官方 app-icon，覆盖应用、托盘、安装器、关于页和商店图标（`9ddcc3c`）。
- 桌面备忘卡片新增加号、锁定、完成、关闭操作列，锁定状态持久化并支持托盘统一解锁（`e4c72dd`）。
- 快捷菜单“功能”动作列表新增“新建备忘录”，复用 `Alt+A` 的新建流程（`d4a2776`）。
- 支持右键卡片标题或正文原位编辑，700ms 自动保存并按内容重算卡片高度（`608234a`、`cfff112`、`449fa30`）。
- 支持每条备忘录独立开启逐行打勾，设置项仅作为新建默认值（`db04089`、`cfff112`）。
- 安装版支持 GitHub Releases 源的应用内更新，包括关于页检查、下载和确认重启安装（`3af399c`）。
- 新增独立 VitePress 官网并部署到 GitHub Pages，包含功能、安装、使用、FAQ、隐私、安全与更新日志（`d2ebbde`、`89b7312`、`d2570ab`）。

## 问题修复

- 修复卡片双击编辑与逐行复选框冲突的问题，改为右键进入编辑（`cfff112`）。
- 修复复选框与首行文字未垂直对齐、锁定卡片透明度过高导致文字难读的问题（`cfff112`）。
- 修复逐行打勾按文本匹配导致改字后勾选状态错位的问题，改为按行号保留完成状态（`449fa30`）。
- 移除编辑态“编辑中…”状态和“完成”按钮，改为“点击空白处保存”的轻量提示（`449fa30`）。
- 修复备忘录设置中快捷键行高于其他设置行、ESA/DeepSeek 设置标题缺少“设置”、自动刷新与配置按钮被迫分成两行的问题（`4e410af`）。
- 修复快捷菜单“功能”按钮缺少与“设置”一致的点击选中反馈（`5b40355`）。
- 修复卡片编辑、逐行模式切换和设置页切换没有过渡动画的问题（`449fa30`、`050d7d5`）。
- 修复弹窗蒙版随背景滚动、下方露出未遮挡内容的问题，弹窗改为挂载到 `document.body`（`050d7d5`）。
- 修复 app-icon 四周留白过大导致任务栏和窗口图标显得过小的问题（`8a75e17`）。

## 安全与稳定性

- 配置文件某个分区损坏时保留其他有效设置，并备份原文件、显示恢复提示（`8f28506`）。
- 打包后不再信任开发服务器地址，更新源覆盖仅接受 HTTPS 或本地回环测试地址（`9d6344c`）。

## 文档与工程

- 重构 TODO 维护规则，取消项直接删除，完成项划线归档到文末（`796f5b0`）。
- 同步发布说明、隐私说明、官网部署、自定义域名和使用文档（`ea1b0ad`、`d2570ab`）。
- 官网新增构建产物的内部链接检查（`d2570ab`）。
- 从本版本起，Release 说明使用仓库内的中文文件 `docs/releases/vX.Y.Z.md`，并标注对应提交 ID。

## 升级说明

- 安装版可直接覆盖安装并保留 `%APPDATA%\FlowerBuddy` 中的配置、凭据、备忘录、提醒、桌宠图片和日志。
- `v0.1.0` 的 Release 缺少 `latest.yml`/blockmap，且该版本没有应用内更新器，不能作为自动更新基线；首次应用内升级验证从 `v0.2.0` 开始。
- 安装包仍未做代码签名，Windows SmartScreen 可能提示“未知发布者”。
- 便携版仍通过手动下载更新，不参与应用内自动更新。

## 下载建议

- **普通用户推荐下载 `FlowerBuddy-Setup-0.2.0-x64.exe`**：安装版，按当前用户安装，支持覆盖升级和卸载入口。
- `FlowerBuddy-Portable-0.2.0-x64.exe`：便携版单文件，免安装，适合 U 盘或临时使用。
- `FlowerBuddy-0.2.0-x64.zip`：便携版压缩包，额外包含使用说明、MIT 许可证、美术素材许可和第三方许可证清单。
- `latest.yml` 与 `FlowerBuddy-Setup-0.2.0-x64.exe.blockmap`：应用内自动更新元数据，请勿删除；普通用户无需下载。
- `SHA256SUMS.txt`：下载校验值，可用 PowerShell `Get-FileHash` 或 `certutil -hashfile` 核对。
