## 1. 锚定卡片拖拽合并

- [ ] 支持将一个桌面锚定卡片拖拽到另一个卡片上合并。
- [ ] 避免正常拖动卡片时误触发合并：需要明确拖拽与合并的区分方式，例如停留时间、专用拖放区域、目标卡片高亮或按住修饰键。
- [ ] 两个卡片都有提醒时间且时间相同时，可以直接合并。
- [ ] 两个卡片提醒时间不同时，仍允许合并，但必须从两个时间中选择一个作为合并后卡片的提醒时间。
- [ ] 只有一个卡片有提醒时间时，合并后保留该提醒时间。
- [ ] 所有合并都需要二次确认。
- [ ] 设置中提供“合并时不再二次确认”的勾选；开启后跳过确认，但不同提醒时间仍必须二选一。
- [ ] 如果时间选择被取消，则取消合并并保持两张卡片原样。
- [ ] 待确认：合并后的正文顺序、图片顺序、完成状态、锚点位置和卡片尺寸如何处理；是否支持撤销；合并后原卡片是否删除以及是否保留历史。

## 2. 锚定卡片直接编辑

- [ ] 评估在桌面锚定卡片上直接编辑正文的可行性。
- [ ] 评估性能开销：编辑状态切换、逐字保存、卡片高度重算、窗口尺寸调整、输入法、图片粘贴和与设置页数据的同步。
- [ ] 待确认：采用原位编辑还是打开现有备忘录编辑器；是否支持图片编辑；编辑期间是否暂停自动排列和提醒；是否需要草稿与撤销。

## 3. 锚定卡片逐行完成勾选

- [ ] 设置中增加一个勾选项；开启后，所有锚定卡片的每一行前显示复选框。
- [ ] 通过勾选/取消勾选表示该行任务完成或未完成。
- [ ] 待确认：按换行还是按列表项拆分任务；完成状态如何存储、与整张卡片的“完成”状态如何联动；已完成行的样式；编辑后行状态如何保持；是否需要迁移旧卡片数据。
