## 1. 前置条件与测试环境

- 在 Windows x64 上测试；优先使用 `npm run dist:win` 产出的 Setup/Portable/`win-unpacked`。
- 使用隔离的 user data 目录，避免读写真实配置；具体参数以当前构建方式为准。
- 准备本机临时 HTTP 服务，提供 200、404、500 和延迟响应端点。
- 准备两块以上显示器（多显示器项）；准备 100%/125%/150%/200% 缩放环境。
- 外部账户测试只使用测试人员自己的凭据，且只在应用设置内输入；不得写入仓库、文档、截图或聊天记录。
- 每轮记录构建版本、提交短哈希、Windows 版本、缩放比例和测试日期。

## 2. 功能验收清单

### 2.1 安装、升级与卸载

- [ ] **I-01 全新安装**：在干净用户环境运行 `花伴-Setup-<version>-x64.exe`，应完成安装，默认仅当前用户安装，可选择安装目录；安装程序、开始菜单与桌面快捷方式使用桌宠形象的图标与“花伴”名称。
- [ ] **I-02 首次启动**：安装后从开始菜单/桌面快捷方式启动，不要求 Node.js、终端或额外运行库。
- [ ] **I-03 升级保留数据**：安装新版本覆盖旧版本后，`config.json`、`secrets.enc.json`、`data/`、`pets/` 与 `logs/` 不被清空，设置和导入图片仍在。
- [ ] **I-04 卸载**：通过 Windows“设置 → 应用”或开始菜单卸载，程序文件被移除；`%APPDATA%\FlowerBuddy` 按说明保留。
- [ ] **I-05 便携版启动**：直接运行 Portable 或解压 ZIP，不依赖安装目录和开发工具。
- [x] **I-06 无 Node 路径启动**：2026-10-17 记录中便携版在移除 Node 路径后成功启动；仍建议在干净虚拟机复测。
- [ ] **I-07 SmartScreen**：未签名安装包应显示“未知发布者”提示；确认 README 未声称已签名。
