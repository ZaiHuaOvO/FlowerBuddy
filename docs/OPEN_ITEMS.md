## 仍需用户参与或外部条件

- [ ] **真实 Gmail OAuth 验证**：需要发布者/用户提供 Google Cloud 项目与“桌面应用”OAuth 客户端，并在应用设置内完成授权。不要通过聊天或仓库提供 Client Secret。
- [ ] **真实 DeepSeek/ESA 账户数据验证**：需用户在应用设置内输入自己的凭据后查看；仓库与测试中只有占位数据。
- [ ] **完全干净的 Windows 环境安装验收**：本次已用移除 Node 路径的便携版做启动验证，仍建议在无开发工具的干净虚拟机完成一次安装/卸载验收。
- [ ] **多显示器物理验证**：需要 2 块以上真实显示器，验证桌宠、菜单、气泡在不同工作区之间的恢复与定位。

- [ ] **托盘图标像素级视觉检查**：已验证图标文件有效、托盘创建成功，未做系统托盘截图检查。
