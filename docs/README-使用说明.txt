花伴 0.1.0 使用说明
================================

一、运行方式
------------
1. 便携版：直接双击本压缩包内的 花伴-Portable-0.1.0-x64.exe，无需安装。
2. 安装版：运行 花伴-Setup-0.1.0-x64.exe，按向导完成安装；默认按当前用户安装。
3. 最终用户不需要安装 Node.js，也不需要打开终端或执行任何命令。

二、首次启动
------------
- 桌宠默认出现在桌面右下角。按住可拖动，单击播放反馈动画，右键打开快捷菜单。
- 托盘图标提供“显示/隐藏桌宠”“打开设置”“退出”。
- 关闭设置窗口不会退出程序；请通过托盘或快捷菜单的红色电源图标（退出 花伴）结束。

三、功能
--------
- 快捷菜单为 4 个白色图标按钮；鼠标移入“功能”按钮会展开快捷功能列表，移出菜单后收起。
- 特殊日期：添加生日、纪念日与一次性事件，支持每年重复、倒计时与停用。
- 网站检测：从本机检查 HTTP(S) 状态、耗时与错误类型；可选定时检测默认关闭。
- DeepSeek 余额：在设置中填写 API Key 后查询余额；不提供官方不支持的“今日花费”。
- ESA 流量：填写只读 RAM AccessKey 与 SiteId 后查询今日累计流量，数据可能采样/延迟。
- Gmail：填写 Google Cloud 桌面应用 OAuth 客户端后连接，只读取发件人/主题/时间等元数据。
- 每个模块都可以在“功能”分页独立启用/停用。

四、数据与隐私
--------------
- 所有数据保存在 %APPDATA%\FlowerBuddy（花伴沿用此目录以兼容旧版本升级），升级和卸载不会删除用户配置。
- 密钥使用 Windows safeStorage 加密保存在 secrets.enc.json，不写入普通配置或日志。
- 应用没有遥测；只在你配置并启用相应模块时访问对应服务。
- 删除全部数据：退出应用后删除 %APPDATA%\FlowerBuddy 目录。

五、卸载
--------
- 通过 Windows“设置 > 应用”或开始菜单中的卸载入口卸载。
- 卸载不会自动删除 %APPDATA%\FlowerBuddy；如需彻底清除请手动删除。

六、安全提示
------------
- 当前安装包未做代码签名，Windows SmartScreen 可能提示“未知发布者”。
- 请只从可信来源获取安装包；不要向任何人提供 API Key 或 AccessKey。
- 更详细的隐私说明见应用仓库中的 PRIVACY.md。

第三方依赖许可证清单随包附在 THIRD_PARTY_LICENSES.md。
