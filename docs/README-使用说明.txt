花伴 0.1.0 使用说明
================================

一、运行方式
------------
1. 便携版：直接双击本压缩包内的 花伴-Portable-0.1.0-x64.exe，无需安装。
2. 安装版：运行 花伴-Setup-0.1.0-x64.exe，按向导完成安装；默认按当前用户安装。
3. 最终用户不需要安装 Node.js，也不需要打开终端或执行任何命令。

二、首次启动
------------
- 桌宠默认出现在桌面右下角。按住可拖动，单击播放反馈动画，右键打开快捷菜单。
- 托盘图标提供“显示/隐藏桌宠”“打开设置”“退出”。
- 关闭设置窗口不会退出程序；请通过托盘或快捷菜单的红色电源图标（退出 花伴）结束。

三、功能
--------
- 快捷菜单为 4 个白色图标按钮；鼠标移入“功能”按钮会展开快捷功能列表，移出菜单后收起。
- 气泡按出现顺序从上到下排列；普通气泡会自动消失，备忘录提醒会一直保留，点击“知道了喵”后关闭。
- 备忘录：进入页面即可看到全部备忘；点击“新增备忘录”或使用快捷键弹出编辑窗口，记录文本、粘贴图片并设置提醒；新增窗口中的“创建后锚定到桌面”开关会被记住。提醒到点后通过桌宠气泡常驻提示，点击“知道了喵”才关闭。可把备忘锚定成桌面卡片（默认从右上角错开排列、置顶、可拖动、四角缩放），卡片上可以完成或取消锚点。
- 新建备忘录默认快捷键为 Alt+A，可在备忘录页标题旁的设置图标中修改；按下后会打开设置并弹出新建备忘录。
- 定时提醒：在“定时提醒”页添加多个提醒，设置名字、开关、提醒间隔（分钟/小时）、生效时间段、±随机值和气泡文本。内置一个默认关闭的“喝水”提醒。提醒到点后会以常驻气泡显示文本，点击“知道了喵”关闭。
- 快捷菜单中的 DeepSeek 余额显示为“大鲸鱼还有 ¥xxx 的米饭可以吃喵”；ESA 流量可按在设置中勾选的过去 24 小时/7 天/30 天显示。
- 普通气泡鼠标停留在桌宠或气泡上时不会自动关闭，移开后才会继续计时并关闭。
- 网站检测：从本机检查 HTTP(S) 状态、耗时与错误类型；可选定时检测默认关闭。
- DeepSeek 余额：在设置中填写 API Key 后查询余额；不提供官方不支持的“今日花费”。
- ESA 流量：填写只读 RAM AccessKey 与 SiteId 后查询过去 24 小时/7 天/30 天的累计流量，可在设置中勾选显示范围；数据可能采样/延迟。
- 每个模块都可以在“功能”分页启用或停用；左侧已启用列表可拖拽调整顺序，设置窗口左侧导航会按相同顺序显示已启用功能。

四、数据与隐私
--------------
- 所有数据保存在 %APPDATA%\FlowerBuddy（花伴沿用此目录以兼容旧版本升级），升级和卸载不会删除用户配置。
- 定时提醒保存在 data\interval-reminders.json，默认仅启用“备忘录”和“定时提醒”两个功能。
- 备忘录文本保存在 data\memos.json，粘贴图片保存在 memo-images 目录，均只在本机处理，不会上传。
- 密钥使用 Windows safeStorage 加密保存在 secrets.enc.json，不写入普通配置或日志。
- 应用没有遥测；只在你配置并启用相应模块时访问对应服务。
- 删除全部数据：退出应用后删除 %APPDATA%\FlowerBuddy 目录。

五、卸载
--------
- 通过 Windows“设置 > 应用”或开始菜单中的卸载入口卸载。
- 卸载不会自动删除 %APPDATA%\FlowerBuddy；如需彻底清除请手动删除。

六、安全提示
------------
- 当前安装包未做代码签名，Windows SmartScreen 可能提示“未知发布者”。
- 请只从可信来源获取安装包；不要向任何人提供 API Key 或 AccessKey。
- 更详细的隐私说明见应用仓库中的 PRIVACY.md。

第三方依赖许可证清单随包附在 THIRD_PARTY_LICENSES.md。
