# 品牌素材

本目录只保留官方 **app-icon**（纯图形、无文字版本）。产品名称、标语和说明文字由界面、README 与官网自行排版，不使用带文字的完整 Logo。

## 文件

- `app-icon/flowerbuddy-icon-transparent-*.png`：透明底图标，16–1024 px，用于界面、托盘、安装器与网页；画布按图形内容居中裁切，四边保留约 3% 安全边距，避免任务栏和窗口标题栏中显得过小。
- `app-icon/flowerbuddy-icon-white-*.png`：白色背景图标，用于需要实体底色的场景。
- `app-icon/FlowerBuddy.ico`：Windows 多尺寸图标（16–256）。

## 使用约定

- Windows 应用与安装包：`FlowerBuddy.ico`。
- 托盘：透明底 64 px 或 32 px。
- 关于页、README、官网：透明底 app-icon + 界面文字；不加载完整组合 Logo。
- 安装器：app-icon + 中文“花伴”等界面文字。
- 不要手工重命名尺寸；新增场景优先复用现有尺寸。
